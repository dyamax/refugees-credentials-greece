# Refugee Credentials Greece

A static informational website designed to provide a clear overview of essential topics relevant to refugees and migrants in Greece, including legal rights, housing, food supply, employment, and education.

## Overview

This project is a front-end website built with plain HTML, CSS, and JavaScript. It presents a multi-page, visually styled experience with navigation, animated sections, and content focused on key practical information for people seeking orientation in Greece.

## Purpose

The site aims to:

- explain important rights and protections
- provide guidance on housing and basic needs
- highlight food access, employment opportunities, and education pathways
- share accessible information in a clean, readable format

## Project structure

- `index.html` — main landing page
- `style.css` — main visual styling
- `keyframes.css` — animation and motion effects
- `app.js` — interactive page behavior and navigation logic
- `index[2[Legal Rights]].html` — legal rights page
- `index[3[Housing]].html` — housing page
- `index[4[Food Supply]].html` — food supply page
- `index[5[Employment]].html` — employment page
- `index[6[Education]].html` — education page
- `photo/` — image assets used across the site
- `video/` — media assets
- `versions/` — alternative or archived version of the project

## How to run locally

Because this is a static website, you can open it directly in a browser:

1. Open the project folder.
2. Double-click `index.html`.
3. Or serve it locally with a simple web server:

```bash
cd "refugees-credentials-greece"
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
